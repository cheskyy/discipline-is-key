# DISCIPLINE IS KEY

*Small Steps. Consistent Actions. Better Me.*

Agenda digital berbahasa Indonesia dengan halaman Hari Ini, Checklist Harian, dan Keuanganku.

- Halaman Hari Ini menampilkan sapaan, tanggal, motivasi, dan ringkasan kegiatan.
- Checklist Harian mendukung penambahan, pengeditan, penghapusan, dan penandaan kegiatan selesai. Kamu bisa melihat kegiatan yang belum selesai dan menyaringnya berdasarkan kategori.
- Contoh kegiatan muncul saat pertama membuka agenda dan bisa diedit atau dihapus. Agenda memakai tanggal setempat dan membuka checklist baru saat hari berganti.
- Catatan agenda dan transaksi disimpan otomatis di browser yang kamu gunakan. Gunakan browser dan alamat website yang sama untuk membuka kembali catatanmu.

## Menggunakan Keuanganku

1. Mulai dengan mencatat uang yang tersedia sebagai pemasukan. Tambahkan pengeluaran saat membayar kebutuhan.
2. Gunakan **Setoran simpanan** untuk memindahkan uang ke tabungan atau dana darurat. Gunakan **Penarikan simpanan** untuk memindahkannya kembali ke saldo utama.
3. Buka **Anggaran** untuk mengubah batas pengeluaran dan rencana simpanan. Batas awalnya Rp250.000 per minggu, Rp45.000 per minggu untuk bensin dan transportasi, serta Rp100.000 per bulan untuk token listrik.
4. Lihat **Ringkasan** untuk membandingkan pemasukan dan pengeluaran. Laporan mingguan dimulai hari Senin. Laporan bulanan dimulai pada tanggal 1.

## Menjalankan di komputer

Pasang Node.js 24, lalu jalankan perintah berikut di folder proyek.

```sh
npm ci
npm run dev
```

Buka alamat yang muncul di terminal. Untuk memeriksa versi yang siap dipublikasikan, jalankan `npm run build` lalu `npm run preview`.

## Publikasi dengan GitHub Pages

1. Buka **Settings → Pages** di repositori GitHub, lalu pilih **GitHub Actions** sebagai **Source**.
2. Buka **Actions → Publikasikan ke GitHub Pages → Run workflow**. Pilih branch **main**, lalu klik **Run workflow**.
3. Setelah proses berhasil, alamat website akan muncul di halaman **Settings → Pages**.

GitHub Free mendukung Pages dari repositori publik. Untuk repositori pribadi, Pages tersedia di paket GitHub yang mendukungnya. [Panduan GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
